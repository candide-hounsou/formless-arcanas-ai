# Real cases research

This folder collects **real-world use-case research briefs** to ground examples and demos in EU/US regulatory drivers.
Each file is a draft research artifact, not a legal opinion. Sources and citations must be verified before use.

## Scope

- Jurisdictions: **EU** and **US**
- Audience: governance, risk, compliance, and audit stakeholders
- Goal: map real-world decisions to `DecisionRecord` requirements

## Structure

- File naming: `RC-XXXX-short-name.md`
- Each brief includes:
  - Summary and decision trigger
  - Regulatory drivers (candidates)
  - DecisionRecord mapping
  - Responsibility chain and temporal validity
  - Data/evidence requirements
  - Replay/traceability considerations
  - Open questions and sources to confirm
